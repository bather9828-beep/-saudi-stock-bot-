# 🇸🇦 بوت تحليل الأسهم السعودية (Saudi Stock Bot)

بوت ذكي ومتكامل لتحليل سوق الأسهم السعودي (تداول)، يعمل تلقائياً عبر GitHub Actions. يوفر تحليلاً فنياً متقدماً، إدارة للمحفظة، وتنبيهات فورية للأسعار.

## ✨ الميزات الرئيسية
- 📊 **تحليل فني شامل:** يدعم RSI, MACD, ADX, OBV, Bollinger Bands، وكشف أنماط الشموع والتقاطع الذهبي/الميت.
- 💼 **إدارة المحفظة:** تتبع عمليات الشراء والبيع، حساب الأرباح/الخسائر، وتحديث أسعار الدخول.
- 🔔 **تنبيهات الأسعار:** إشعارات فورية عند وصول السهم لسعر مستهدف (فوق أو تحت).
- 📈 **مؤشر تاسي والخوف والطمع:** متابعة حية لأداء السوق العام ومؤشر TASI.
- 🧠 **تعلم ذاتي:** يقوم البوت بمراجعة دقة توقعاته وتعديل معاييره تلقائياً لتحسين الأداء.
- 📰 **تقارير دورية:** تقارير أخبار يومية وتقرير أداء أسبوعي شامل.

## ⚙️ جدول العمل التلقائي
يعمل البوت تلقائياً عبر GitHub Actions وفقاً لتوقيت السوق السعودي:
- **الأيام:** من الأحد إلى الخميس.
- **الأوقات:** من 10:00 صباحاً إلى 3:00 عصراً (بتوقيت السعودية).
- **التكرار:** كل 5 دقائق.
*(ملاحظة: يتوقف البوت تلقائياً في عطلة نهاية الأسبوع وبعد إغلاق السوق لتوفير موارد GitHub).*

## 💬 قائمة الأوامر المتاحة

| الأمر | الوصف | مثال |
|---|---|---|
| `/help` | عرض قائمة المساعدة والأوامر | `/help` |
| `/stock [رمز]` | تحليل فني مفصل لسهم معين | `/stock 2222` |
| `/scan` | فحص شامل وعرض أفضل 3 فرص حالياً | `/scan` |
| `/portfolio` | عرض ملخص أرباح وخسائر المحفظة | `/portfolio` |
| `/buy [رمز] [عدد] [سعر]` | تسجيل عملية شراء في السجل | `/buy 1120 10 85` |
| `/sell [رمز] [عدد] [سعر]` | تسجيل عملية بيع وحساب الربح | `/sell 1120 5 90` |
| `/alert [رمز] [سعر] [نوع]` | إضافة تنبيه سعر (above/below) | `/alert 2010 30 above` |
| `/watchlist` | عرض أو إدارة قائمة الأسهم المتابعة | `/watchlist add 7010` |
| `/capital [مبلغ]` | تحديث ميزانية التداول الافتراضية | `/capital 50000` |
| `/weekly` | عرض التقرير الأسبوعي الشامل | `/weekly` |

## 🛠️ المتطلبات التقنية
- Python 3.10+
- مكتبات: `yfinance`, `requests`, `pandas`, `numpy`, `pytz`
- بيئة التشغيل: GitHub Actions
